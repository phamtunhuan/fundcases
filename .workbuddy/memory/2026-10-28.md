## 私募基金监管处罚案例库（AMAC 纪律处分爬虫 + GitHub Pages 站点）

目标：抓取中国证券投资基金业协会「自律管理 → 纪律处分 → 受处分机构」栏目，做案例库并发布为 GitHub Pages 网站。

### 数据源要点
- 栏目地址 https://www.amac.org.cn/zlgl/jlcf/scfjg/index.html ，共 35 页（index.html 为第 1 页，index_2 ~ index_34），每页 18 条，末页 3 条，合计 **597 条**（2015-01 ~ 2026-10）。
- 列表项结构：`<li><span></span><a href="...">标题</a><i>日期</i></li>`；分页参数在 `createPageHTML(35, N, "index","html")`。
- 详情页两类：扫描版 **PDF**（480 份，无文本层）+ 网页版 **HTML**（117 份，正文在 `<div class="content">`）。
- 协会机构公示接口 `gs.amac.org.cn/amac-infodisc/api/pof/manager` 有防护，且被罚机构多已注销，查不到类型 → 放弃，改用启发式分类。

### 技术方案（已落地脚本）
- `scripts/crawl_list.py` 抓列表；`download_docs.py` 8 并发下载原文（542 MB）。
- `ocr_vision.py` 用 **macOS Vision 框架**（pyobjc-framework-Vision/Quartz）OCR 扫描 PDF：597 份耗时约 3 分 46 秒（6 进程），SCALE=2.0，中文识别质量可用。
  - 坑：`Foundation.URLWithString_` 不存在，须用 `Foundation.NSURL.fileURLWithPath_`。
- `build_json.py` 负责标签化：文书类型、当事人（括号配对解析，兼容嵌套括号与截断标题）、管理人类型（正文声明 > 机构名 > 正文词频，覆盖率约 90%）、地区（正文「XX证监局」优先）、20 类违规事由、12 类处分措施。
- `build_site_data.py` 拆成 `docs/data/cases.json`（444K 索引）+ `texts.json`（2.8M 正文，点击懒加载）。

### 站点
- `docs/` 零依赖静态站（自写 CSS 柱状图/条形图，不引 CDN）：统计卡片、年度趋势、措施/事由分布、多维筛选 + 搜索 + 分页、详情弹窗。
- 必须通过 HTTP 访问（file:// 下 fetch 会被拦截），本地 `cd docs && python -m http.server 8000`。
- 用户决策记录：案例库要做「元数据 + OCR 全文」深度；范围「全量保留 + 加管理人类型标签」，不筛掉股权类。

### 第二轮优化（已推送 8b86c1a）
用户需求：正文排版连贯不要断行 + 提升机构/当事人、地区、处分措施精度。
- **reflow()**：OCR 按视觉行输出会切碎段落。按「行首缩进≥2 且首字为中文」+ 编号模式（一、（一）1.）判定段落起点，段内直接拼接（ASCII 之间补空格），段落间空一行。
- **OCR 错字是精度第一杀手**：撒销/撇销/撖销→撤销、皙儜→暂停、遣贵/谴费→谴责、繁体（暫停/備案/會員）需 OpenCC t2s 归一。措施正则必须允许机构名夹在动词与宾语之间（`撤销[\u4e00-\u9fa5]{0,25}?管理人登记`）。
- **措施标注只信「协会决定作出以下纪律处分：XXX。」这句**（DECISION_SENT），用全文或章节兜底会误命中法规引用/套话（如「注销市场主体登记」被误判为注销管理人登记）；撤销与注销互���。
- 效果：无措施 306→94（多是送达公告本就无措施）；空机构名 38→12（补齐〔〕【】[] 括号配对）；空地区 50→26（补全省市词典+括号内地名）。
- 新增 `penalty_text`（决定原文短句）/ `decision_text`（决定章节），网站弹窗展示处分决定原文便于人工核对；这两字段不入 docs/data/cases.json 索引外的 decision_text（体积考虑）。

### 第三轮：协会公示核对管理人类型（已推送 1edabf0）
用户指定两个查询源：在册 managerList.html 与已注销 cancelled/manager/index.html。
- 接口：POST `gs.amac.org.cn/amac-infodisc/api/pof/manager/query`（在册，取 primaryInvestType）；未命中再 POST `api/cancelled/manager`（列表仅 orgName/userTenantId）→ GET 详情页 `{tid}.html`，服务端渲染含 `<td>机构类型</td>`。
- 脚本：scripts/query_amac_type.py（主查询+缓存 data/manager_types.json）+ query_amac_type_fix.py（简称全称映射、变体、非私募分类）。
- 命中 496/524（94.7%）：93% 精确匹配、7% 简称↔全称；28 个未查到（多是被撤销登记后从公示移除）；11 个非私募对象（公募/券商/基金子公司/销售机构）单独标注。
- **重大纠偏**：正文词频启发式把证券类高估为 449 例，公示核对后为 292 证券/271 股权创业——启发式不可信，已全部换成权威来源。
- 坑：协会 keyword 是连续子串匹配，全名带「（北京）」等括号插词查不到，需拆字号；「金时（厦门）」会误匹配到「杭州金时」（不同主体），匹配置信度阈值必须保留。
